# WinMorph

**Windows-Looks per Klick.** · Download: **[winmorph.benjaminberger.at](https://winmorph.benjaminberger.at)**

 WinMorph legt ein komplett eigenes Design über Windows 10/11 – Taskleiste, Startmenü, Titelleisten, Alt+Tab, Hintergrund und Sperrbildschirm. **Deine Windows-Einstellungen bleiben dabei unverändert** (kein Dunkelmodus-, Akzent-, Maus- oder Explorer-Umbau), außer du schaltest das pro Look selbst ein. Alles lässt sich mit einem Klick vollständig zurücksetzen.

## Presets (16)

| Gruppe | Presets |
|---|---|
| Windows-Klassiker | Windows 11 (Standard), Windows 10, Windows 7, Windows XP, Windows 95 |
| Apple | macOS (hell oder dunkel umschaltbar) |
| Linux & Co. | Ubuntu, Debian, Arch Linux, Linux Mint, ChromeOS |
| Zukunft & KI | Nexus AI (reines KI-System), NovaOS (erfundenes OS), Hacker |
| Spezial | Zen (Ruhe & Fokus), Gaming (Spiele & Leistung) |

## Jeder Look ist einstellbar

Beim Look wählst du selbst, was angewendet wird. Die Auswahl merkt sich jeder Look einzeln.

- **Standard (nur WinMorph-Design):** Design-Oberfläche, Desktop & Hintergrund, Sperrbildschirm.
- **Optional, ändert Windows-Einstellungen (Standard aus):** Farben & Hell/Dunkel, Taskleiste, Startmenü, Fenster & Bewegung, Systemschrift, Mauszeiger, Systemklänge.

Jeder Wechsel startet vom Original-Windows aus: Was beim neuen Look aus ist, ist wieder wie vorher – vom alten Look bleibt nichts zurück.

## Design-Shell – das echte Aussehen

WinMorph ersetzt die Windows-Taskleiste und das Startmenü durch eigene, vollständig gezeichnete Varianten im Stil des gewählten Systems:

| Look | Taskleiste | Startmenü |
|---|---|---|
| Windows 95 | graue 3D-Leiste, „Start“-Knopf, Fenster-Schaltflächen mit Beschriftung | klassisch mit blauem Seitenbanner und „Programme ▸“ |
| Windows XP | blaue Luna-Leiste, grüner „start“-Knopf, hellblauer Infobereich | zweispaltig mit Benutzerkopf, „Alle Programme“, Abmelden/Ausschalten |
| Windows 7 | Glas-Leiste mit Startkugel | Programme + Suche links, Ordner-Spalte rechts, „Herunterfahren ▸“ |
| Windows 10 | flache Leiste, Suchfeld | App-Liste + Kacheln |
| macOS | Menüleiste oben mit App-Name, Dock unten mit Vergrößerung | Launchpad (Vollbild-App-Raster) |
| Ubuntu | GNOME-Leiste oben + Dock links | Vollbild-Übersicht |
| Debian | GNOME-Leiste oben + Dock unten | Vollbild-Übersicht |
| Linux Mint | Cinnamon-Leiste | Menü mit Suche und Orten |
| ChromeOS | Regal mit Launcher-Kreis | App-Raster |
| NovaOS / Zen | schwebende Leiste | App-Raster bzw. Suchpalette |
| Hacker | Statuszeile mit Netz/CPU/RAM/Lautstärke/Akku/Uhr, eigene Panels | echtes Terminal mit über 50 Befehlen |
| Arch Linux | schwebende Waybar mit Fenster-Nummern, CPU-/RAM-/Netz-/Uhr-Modulen | Rofi-artiger Starter |
| Nexus AI | keine Taskleiste – nur eine schwebende KI-Befehlszeile | Vollbild-KI-Hub, versteht Befehle |
| Gaming | kantige rote Leiste mit CPU/GPU/RAM/Ping | App-Liste mit schrägen Kacheln |

Außerdem in jedem Look:

- **Alt+Tab** wird durch einen eigenen Umschalter ersetzt (klassisch, mit Live-Vorschau, große Symbole oder Textliste).
- **Windows-Taste, Strg+Esc und Win+X** öffnen immer die neuen Menüs (Win+X = Schnellmenü für Profis).
- **Win+C und die Copilot-Taste** öffnen ChatGPT; jede KI-Frage geht an ChatGPT.
- **Live-Vorschau** beim Darüberfahren über Taskleiste/Dock, **Anheften/Lösen** per Rechtsklick, **Mittelklick** = neues Fenster.
- Leisten auf **allen Bildschirmen**, Akku-Anzeige bei Laptops.
- **Eigener Sperrbildschirm** im Stil des Looks (läuft als kennwortgeschützter Bildschirmschoner, die sichere Windows-Anmeldung bleibt erhalten) und **eigenes Sperrbild** ohne Werbung.
- In allen Suchfeldern versteht WinMorph Befehle wie „öffne Firefox“, „dunkel“, „lauter“, „sperren“, „screenshot“ – alles andere wird ChatGPT gefragt.

Dazu bekommen die **Titelleisten aller Programme** die Farben des Looks (die Fensterränder bleiben immer neutral), und die **Windows-Taste** öffnet das neue Menü. Maximierte Fenster lassen Platz für die neuen Leisten wie bei der echten Taskleiste. Der Shell startet automatisch bei der Anmeldung.

## Hacker-Look

Der komplette Hacker-Look in Schwarz und einer Farbe deiner Wahl, ohne Standard-Windows-Oberflächen:

- **Farbe frei wählbar:** Grün, Cyan, Bernstein, Rot, Violett, Weiß oder eine eigene Farbe (in der App beim Hacker-Look unter „Farbe“). Leiste, Terminal, Panels, Benachrichtigungen, Desktop und Sperrbildschirm übernehmen sie.
- **Ruhiger Desktop mit Live-Systeminfos** (Uhr, Datum, CPU, RAM, Laufwerke, Netz, Akku, WLAN, IP) neben deinen Desktop-Symbolen. Er zeichnet nur einmal pro Sekunde und pausiert bei maximierten Fenstern – spart Akku.
- **Neutrale Fensterrahmen:** dunkle Titelleisten, kein farbiger Rand um jedes Fenster.
- **Eigener Task-Manager** (Strg+Umschalt+Esc, `taskmgr`): Prozesse mit CPU und RAM, Filter, Sortieren, Beenden (Entf), zum Fenster wechseln (Enter), Ordner öffnen. Wichtige Windows-Prozesse sind geschützt.
- **Eigener Datei-Explorer** (Win+E, `files [pfad]`): Orte und Laufwerke, Filter, öffnen, kopieren/ausschneiden/einfügen (Strg+C/X/V, auch mit dem Windows-Explorer), umbenennen (F2), in den Papierkorb (Entf), neuer Ordner (Strg+Umschalt+N), versteckte Dateien (Strg+H), Eigenschaften, Terminal hier. Ordner aktualisieren sich von selbst.
- **Eigenes Win+R:** `run>`-Zeile mit Verlauf (↑↓), Strg+Umschalt+Enter startet als Admin.
- **Eigene Benachrichtigungen:** Meldungen aller Apps erscheinen als Terminal-Banner oben rechts (sie bleiben zusätzlich in der Windows-Mitteilungszentrale). Dazu eigene Meldungen für WLAN verbunden/getrennt, Netzteil an/aus, Akku niedrig und abgelaufene Timer.
- **WLAN trennen und verbinden:** im Netz-Panel (Klick auf die Netzanzeige) oder im Terminal mit `wifi`, `wifi connect <name>`, `wifi off`. Neue Netze fragen das Passwort direkt im Panel ab.
- **Windows-Taste = Terminal** (winmorph-sh) mit über 50 Befehlen, Verlauf (↑↓) und Tab-Vervollständigung:
  - App-Namen tippen: Unter der Eingabe zeigt eine Liste, was Enter macht (oberste, markierte Zeile). Mit ↑↓ wählst du eine andere Zeile, Tab ergänzt den Namen. Gesucht wird auch nach Programmnamen und üblichen Kurznamen (`code`, `chrome`, `calc`, `notepad`, `cmd`).
  - Apps haben Vorrang. Ein WinMorph-Befehl gewinnt nur, wenn er wirklich gemeint ist. Unbekannte Wörter werden nie als Befehl ausgeführt, die Liste bietet dann Websuche oder ChatGPT an. Echte cmd-Befehle mit `!` davor (z. B. `!ipconfig /all`) oder bekannte Programme mit Argumenten (`git status`); `ps1 …` läuft in PowerShell.
  - Weitere Befehle: `neofetch`, `top`, `ps`, `kill`, `ip`, `ping`, `dns`, `myip`, `wifi`, `weather`, `ls`, `cd`, `cat`, `find`, `hash`, `clip`, `note`, `timer`, `calc`, `wall`, `windows`/`focus`, `vol`, `lock`, `reboot`, `shutdown` …
  - `? frage` fragt ChatGPT.
- **Statusleiste** oben. Netz, CPU (mit Verlauf), RAM, Lautstärke (Mausrad), Akku, Uhr und `[pwr]` öffnen eigene Panels statt der Windows-Fenster:
  - System-Monitor mit Prozessliste und Beenden
  - Netzwerk mit WLAN-Liste (trennen/verbinden), Ping und öffentlicher IP
  - Lautstärke
  - Kalender
  - Energie: sperren, Energie sparen, Ruhezustand, abmelden, neu starten, herunterfahren (mit Bestätigung)
- **Lautstärketasten** zeigen eine eigene Anzeige statt der Windows-Einblendung.
- **Alt+Tab** als Prozess-Tabelle (Nr., PID, Prozess, Titel) mit Live-Vorschau.
- **Eigener Sperrbildschirm, komplett ohne Windows-11-Optik:** Matrix, Boot-Log, große Uhr, „SYSTEM LOCKED“ mit Glitch-Effekt und Statuszeile – und das **Windows-Passwort wird direkt dort eingetippt** (`password for benj: ••••`). Geprüft wird gegen dein Windows-Konto. **F1** = Windows Hello (Fingerabdruck, Gesicht, PIN), **F2** = normale Windows-Anmeldung. Er erscheint bei Win+L, bei „lock“/[pwr] und nach 10 Minuten ohne Eingabe.
  - Sicherheit: Während er angezeigt wird, sind Windows-Taste, Alt+Tab, Alt+F4, Strg+Esc und der Task-Manager gesperrt. Bei Strg+Alt+Entf, wenn sich ein anderes Fenster dauerhaft davor schiebt, bei 5 falschen Passwörtern, beim Energiesparen oder bei einem Fehler übernimmt sofort die echte Windows-Sperre.
  - Nach dem Aufwachen aus dem Energiesparmodus (Deckel zu) verlangt Windows selbst die Anmeldung – dort ist das Matrix-Design das Hintergrundbild.
  - Windows sperrt bei Win+L sofort selbst. Damit stattdessen der Matrix-Sperrbildschirm kommt, schaltet WinMorph die Windows-eigene Win+L-Sperre ab, solange der Design-Shell läuft. Dafür ist **einmal eine Admin-Abfrage** beim Anwenden nötig. Geht der Bildschirm aus, schläft der PC oder endet der Shell, ist die normale Windows-Sperre sofort wieder aktiv.
  - Das **Windows-Sperrbild** (Deckel zu, nach dem Energiesparen) ist das Matrix-Sperr-Design als Bild. Die Uhr darauf kommt von Windows.
- **Tastenkürzel wie unter Linux:** Win+Enter öffnet ein Terminal, Win+1…9 holt ein Fenster nach vorn, Win+Umschalt+Q schließt das Fenster.

## Zen-Look

- **Landschaft, deren Licht der Tageszeit folgt** (Morgen, Tag, Abend, Nacht), mit großer ruhiger Uhr, Datum und einem Gedanken des Tages. Ändert sich nur einmal pro Minute – praktisch kein Akkuverbrauch.
- **Fokus-Timer** in der Leiste: 25 Minuten Fokus, dann 5 Minuten Pause, sanfte Hinweise.
- **Atemübung** (≋): eine Minute im Vollbild – einatmen, halten, ausatmen.
- **Hintergrundklang** (♪): Rauschen oder Regen zum Konzentrieren, direkt im Programm erzeugt.
- Sanfte Benachrichtigungen im Zen-Stil, keine Desktop-Symbole, schlichter Sperrbildschirm.

## Gaming-Look

- **Spiele-Bibliothek** (🎮 in der Leiste): alle installierten Steam- und Epic-Spiele mit Bild, Suche, Start mit einem Klick, zuletzt gespielte zuerst.
- **Leistungsmodus** (⚡): schaltet Windows auf „Beste Leistung“ (bzw. Höchstleistung) und beim Ausschalten oder Beenden automatisch zurück.
- **Live-Werte in der Leiste:** CPU, GPU, RAM und Ping. **Overlay im Spiel** mit Win+Umschalt+F (klickt durch, bleibt oben).
- **Gaming-Desktop** mit Uhr und Live-HUD (CPU, GPU, RAM, Ping, Netz, Akku), roter Sperrbildschirm.

## Live-Hintergründe

Eigener Bereich in der App, unabhängig vom Look:

- **Ruhig & sparsam:** Zen-Landschaft, Gaming-HUD und Hacker-Desktop – zeichnen nur einmal pro Sekunde bzw. Minute.
- **Eigene Animationen:** Matrix (grün/rot/cyan), Matrix + HUD, Terminal-Log, Radar, Netzwerk, Sternenflug und Lichter. Sie reagieren auf Maus und Klicks.
- **Eigene Datei:** ein Video oder ein Bild mit Parallax-Effekt.
- Der Hintergrund läuft hinter den Desktop-Symbolen. Er pausiert automatisch, wenn ein Fenster maximiert ist oder der PC gesperrt ist, und braucht dann keine Leistung.
- Wie alles andere lässt er sich mit „Letzten Look rückgängig“ oder „Original wiederherstellen“ zurücknehmen.

## Immer zurück – egal was passiert

- **„Letzten Look rückgängig“** – zurück zum vorherigen Look (beliebig viele Schritte).
- **„Original wiederherstellen“** – Windows exakt wie vor der ersten Nutzung: Hintergrundbild (auch **Windows-Blickpunkt** oder Diashow – das Bild wird vorher gesichert), Sperrbildschirm (auch Blickpunkt), Bildschirmschoner, Benachrichtigungen, Klänge, Schriften …
- Beides auch im **Windows-Startmenü → WinMorph** und im Win+X-Menü des Shells.
- **Notfall-Taste Strg+Alt+Umschalt+F12** beendet den Design-Shell sofort, die normale Taskleiste ist zurück.
- Der Shell **repariert sich selbst**: Bei einem Fehler baut er sich neu auf; bei wiederholten Fehlern gibt er die Windows-Taskleiste zurück.
- Befehlszeile: `WinMorph.exe --restore`, `--undo`, `--shell-stop`.

## Läuft flüssig – auch bei Grafikproblemen

Menüs werden einmal vorbereitet und danach nur ein-/ausgeblendet, Symbole werden im Hintergrund vorgeladen, die Tastatur läuft in einem eigenen Thread. Falls der Grafiktreiber einmal hängt (Fenster bleiben weiß), erkennt WinMorph das automatisch und schaltet auf Software-Darstellung um.

## Was ein Preset sonst noch ändert

- **Taskleiste:** links/zentriert, Gruppierung bzw. Beschriftung, Suche, Taskansicht, Widgets, Copilot, automatisch ausblenden, Sekunden in der Uhr
- **Startmenü:** Layout, Empfehlungen; mit Open-Shell echtes 95-/XP-/7-Startmenü
- **Farben:** Hell/Dunkel (System und Apps getrennt), Akzentfarbe, Transparenz, farbige Taskleiste und Titelleisten
- **Fenster & Bewegung:** Animationen, Fensterinhalt oder nur Rahmen beim Ziehen, Snap, Schütteln, Schatten, Fokus folgt Maus, ClearType, Menüverzögerung, klassisches Rechtsklick-Menü, kompakter Explorer
- **Systemschrift:** Titelleisten, Menüs, Dialoge und Desktop-Symbole (z. B. Tahoma fett für XP)
- **Desktop:** eigens gezeichneter Hintergrund, Desktop-Symbole, „Dieser PC“
- **Mauszeiger:** Aero, klassisch (95/XP), schwarz
- **Systemklänge:** Standard oder stumm
- **Optional (Admin):** Sperrbildschirm

Bis auf Desktop und Sperrbildschirm ändern diese Bereiche Windows-Einstellungen und sind deshalb standardmäßig aus (siehe „Jeder Look ist einstellbar“).

## Sicherheit

- Beim ersten Anwenden wird automatisch ein **Backup** angelegt (`%LOCALAPPDATA%\WinMorph\backup.txt`). Es speichert jeden Wert **vor** der ersten Änderung – auch wenn du danach mehrere Presets durchprobierst.
- **„Original wiederherstellen“** setzt alles auf diesen Stand zurück.
- Notfall ohne Oberfläche: `WinMorph.exe --restore`
- Normale Änderungen betreffen nur dein Benutzerkonto, keine Admin-Rechte nötig.

## Systemvoraussetzungen

Windows 10 oder 11 (nutzt das in Windows eingebaute .NET Framework 4.8).

**Installieren:** `WinMorph-Setup.exe` starten → „Installieren“. WinMorph kommt nach `%LOCALAPPDATA%\Programs\WinMorph` (keine Admin-Rechte nötig), ins Startmenü, auf Wunsch auf den Desktop und unter Einstellungen → Apps. Auf Wunsch wird der Hacker-Look gleich aktiviert; er startet dann bei jedem Systemstart automatisch, und schon der Sperrbildschirm beim Hochfahren zeigt das Hacker-Design. `WinMorph-Setup.exe /S` installiert ohne Fenster.

**Deinstallieren:** Einstellungen → Apps → WinMorph. Windows wird dabei auf den Zustand vor WinMorph zurückgesetzt.
Hinweis: Windows SmartScreen kann beim ersten Start warnen, weil die Datei nicht signiert ist → „Weitere Informationen“ → „Trotzdem ausführen“.

## Updates

WinMorph aktualisiert sich selbst. Die installierte Version fragt `https://winmorph.benjaminberger.at/api/release` nach der neuesten Version, lädt das Setup herunter und prüft Größe und SHA-256, bevor sie es installiert (`WinMorph-Setup.exe /S /update`). Deine Looks bleiben dabei, wie sie sind.

- **App offen:** In der Seitenleiste erscheint „Version x ist da“ mit „Jetzt aktualisieren“ (WinMorph startet danach neu). Mit „Updates automatisch installieren“ wird ein geladenes Update auch beim Schließen installiert.
- **Nur der Design-Shell läuft:** Er sucht drei Minuten nach der Anmeldung und dann alle sechs Stunden nach Updates und installiert sie, sobald der PC zwei Minuten nicht benutzt wurde (die Leiste ist dann für ein paar Sekunden weg).
- Abschalten: Schalter „Updates automatisch installieren“ in der Seitenleiste. Eine nicht installierte (portable) Kopie verweist nur auf die Website.

## Release

Die Versionsnummer steht an einer Stelle: `Directory.Build.props`. Jeder Push baut WinMorph auf Windows (`.github/workflows/build.yml`), führt den Selbsttest aus und erzeugt Screenshots aller Looks (Artefakt „screenshots“). Steht auf `main` eine Version ohne Tag, wird daraus automatisch ein GitHub-Release mit `WinMorph-Setup-<version>.exe` und `SHA256SUMS.txt`. Die Website und das Update in der App holen es von dort.

## Website

`website/` ist die Seite für `winmorph.benjaminberger.at` (statisch plus ein kleiner Cloudflare Worker für `/api/release` und `/download/setup`, siehe `website/README.md`). Sie wird bei Änderungen und nach jedem Release automatisch ausgerollt.

## Bauen

```
dotnet build WinMorph.csproj -c Release -o build
dotnet build Setup/WinMorphSetup.csproj -c Release -o Setup/out
```
Der Installer (`Setup/out/WinMorph-Setup.exe`) enthält die zuvor gebaute `build/WinMorph.exe`.

## Befehlszeile

| Befehl | Wirkung |
|---|---|
| `--apply <id>` | Preset ohne Oberfläche anwenden (z. B. `--apply xp`) |
| `--restore` | Alles wiederherstellen |
| `--undo` | Letzten Look rückgängig machen |
| `--shell-stop` | Design-Shell beenden (Windows-Taskleiste kommt zurück) |
| `--live-set <id\|off>` | Live-Hintergrund setzen (IDs siehe `wall list` im Terminal) |
| `--live-stop` | Live-Hintergrund beenden |
| `--lockscreen-preview <id> <png>` | Sperrbildschirm als Bild speichern (ändert nichts) |
| `--shell-preview <id> <png> [menu]` | Vorschau des Shells als Bild speichern (ändert nichts) |
| `--live-preview <scene> <png>` | Live-Hintergrund als Bild speichern (z. B. `zen-desk`) |
| `--app-preview <tasks\|files\|games> <png>` | Bildschirmfoto von Task-Manager, Explorer oder Spiele-Bibliothek |
| `--selftest <datei>` | Backup/Restore an einem Test-Schlüssel prüfen |
| `--uninstall` | WinMorph deinstallieren (mit Rückfrage) |
| `--wifi-list <datei>` | sichtbare WLAN-Netze in eine Datei schreiben (Test) |

Preset-IDs (terminal = Hacker): win11, win10, win7, xp, win95, macos, ubuntu, debian, arch, mint, chromeos, nexus, nova, terminal, zen, gaming

Alle Hintergrundbilder werden im Programm selbst gezeichnet. „Windows“, „macOS“, „Ubuntu“ usw. sind Marken ihrer Inhaber; WinMorph ist ein unabhängiges Projekt und ahmt nur den Stil nach.
